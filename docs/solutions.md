# 各关卡通关顺序

下表是每一关的一组可行通关顺序，由 `solver.py` 求出，并已在游戏里按这个顺序实际点完（括号内是"第几行第几列"，从 1 开始）。

| 关卡 | 箭头数 | 失误次数 | 通关顺序 |
| --- | --- | --- | --- |
| 第 1 关 | 5 | 3 | (5,3) → (3,3) → (5,4) → (2,4) → (2,3) |
| 第 2 关 | 7 | 3 | (2,3) → (2,1) → (3,3) → (4,4) → (5,2) → (4,2) → (5,5) |
| 第 3 关 | 10 | 3 | (1,4) → (1,1) → (3,5) → (3,1) → (5,2) → (2,2) → (6,3) → (4,3) → (4,6) → (6,6) |
| 第 4 关 | 13 | 3 | (1,2) → (1,4) → (2,4) → (2,1) → (3,3) → (3,6) → (1,6) → (6,2) → (4,2) → (4,5) → (5,5) → (6,5) → (6,1) |
| 第 5 关 | 15 | 4 | (1,3) → (1,5) → (3,2) → (4,3) → (4,6) → (5,2) → (5,5) → (6,1) → (6,5) → (7,4) → (2,4) → (2,1) → (7,6) → (3,6) → (7,2) |

说明：每一步都是当前棋盘上"前方没有箭头"的箭头，按顺序点击全部可以飞出；顺序不唯一，只要每次点掉的都是能飞出的箭头就不会卡住。
